# MONOLITH — assets and provenance

- Three.js r180 (`vendor/three.module.js`, `vendor/three.core.js`): Three.js Authors, MIT. Full license in THREE-LICENSE.txt. The unmodified official-distribution files were available locally and copied into this isolated prototype; no code from another personal project was imported.
- Space Grotesk Latin variable WOFF2: Space Grotesk Project Authors, SIL Open Font License 1.1. Full license in SPACE-GROTESK-OFL.txt. The existing website's font distribution is preserved and copied here.
- Architecture, bevel geometry, material height/normal/roughness maps, contact-shadow texture, in-world text, light-shaft shader, post-processing, favicon and all procedural audio: generated by the original source in this prototype. No stock models, HDR photographs, third-party music or downloaded material textures are used.

The material textures and audio are synthesized at runtime and do not require separate downloads. The same deterministic material seed is used on each load. No external image, audio, analytics or AI service is called by the experience.

Three.js project: https://github.com/mrdoob/three.js/tree/r180
Font project: https://github.com/floriankarsten/space-grotesk

The original prototype source is delivered to the project owner. No license grant for that original source is implied by the MIT and OFL notices for third-party assets.
